# A-4K Skyhawk for Nuclear Option

The Royal New Zealand Air Force's Douglas A-4K Skyhawk, as upgraded under Project Kahu, as a flyable aircraft for
both factions. **Alpha**: flyable and armed, still being refined.

- Real dimensions and layout from the official flight manuals (NAVAIR 01-40AVC-1 NATOPS, RNZAF NZAP 6213.005-1).
- Rank 1 light attack jet with radar, sitting between the Compass and the Vagrant. Flight model is tuned for
  gameplay on top of real data (J52-P-8 turbojet, real wing).
- Five stations (centreline, two inner and two outer wing pylons), tail hook, two internal 20 mm Mk 12 cannons.
- Three RNZAF liveries, one per real era: No. 75 Squadron 1970s camouflage, the 1984-97 low-visibility wraparound,
  and the 1997-2001 overall green.
- Forward-retracting gear with wells and doors, rear-hinged canopy, side speed brakes.

## Install
Use the **Nuclear Option Mod Manager (NOMM)**: find **A-4K Skyhawk** (pre-release) and install it. It needs
**Blueprinter**, which NOMM installs automatically.

Manual: install BepInEx 5 and Blueprinter 2.0.1, then put the `.nobp` file from the latest release into
`BepInEx/plugins/com.nikkorap.blueprinter/addons/habaneroandroid.a4k/`.

## Known limitations (alpha)
- The cockpit interior is borrowed from the T/A-30 Compass (displays show two engines). An A-4K cockpit is planned.
- Squadron badges are simplified; some markings and dimensions are estimated pending better references.
- Single-player tested. Multiplayer needs every player to have the mod.
